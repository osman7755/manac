manac — как установить на iPhone (через GitHub Pages, бесплатно)

1. Зайди на github.com и зарегистрируйся (если ещё нет аккаунта).
2. Справа вверху «+» → «New repository».
   Имя: manac. Выбери «Public». Нажми «Create repository».
3. На странице репозитория нажми ссылку «uploading an existing file».
4. Открой распакованную папку manac, выдели ВСЁ, что внутри (Ctrl+A),
   и перетащи в окно браузера. Саму папку не перетаскивай — только содержимое.
   Этот файл (ИНСТРУКЦИЯ.txt) можно не загружать.
5. Внизу нажми «Commit changes».
6. Settings → слева «Pages» → Source: «Deploy from a branch»,
   Branch: «main», папка «/ (root)» → Save.
7. Подожди 1–2 минуты. Адрес будет: https://ТВОЙ_НИК.github.io/manac/

На iPhone:
8. Открой этот адрес в Safari.
9. «Поделиться» (квадрат со стрелкой) → «На экран «Домой»» → «Добавить».
10. Запускай manac с иконки: откроется на весь экран, работает без интернета.

Как обновлять:
— Получаешь новую папку manac → снова «Add file» → «Upload files» →
  перетаскиваешь всё содержимое → «Commit changes».
— Через минуту-две при следующем открытии приложения на телефоне будет новая версия.
  Если сразу не подхватилось — закрой приложение (смахни) и открой ещё раз.
— Старые файлы app.xxxx.js можно удалить из репозитория, они больше не нужны.

Важно:
— Данные хранятся на самом телефоне, в GitHub их нет. Код в репозитории виден всем,
  твои задачи и заметки — никому.
— Перенести данные с компьютера: на компьютере Настройки → Экспорт,
  отправь файл себе на телефон, в manac на телефоне: Настройки → Импорт.
— Бэкап с телефона: Настройки → Экспорт → «Сохранить в Файлы».
